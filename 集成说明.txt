================================================================
VS Bridge 集成说明 — 小龙虾 ↔ 克劳德桥接接口
================================================================

## 启动监控（在克劳德那台电脑上运行）
```bash
python E:/zhuomian/vs_bridge.py
```
会持续监控 VS Code 中克劳德的状态，自动截图OCR发送到微信。

## 小龙虾可用的命令

### 1. 查看克劳德状态
```bash
python E:/zhuomian/vs_bridge.py --status
```
返回：正工作 / 任务完成 / 暂无工作在进行

### 2. 读取状态文件（无需运行脚本）
```bash
cat E:/zhuomian/vs_bridge_status.json
```
内容示例：
{
  "state": "正工作",
  "detail": "克劳德正在生成回复...",
  "time": "2026-06-28 18:30:00"
}
状态值：正工作 | 任务完成 | 暂无工作在进行 | 空闲中 | 已停止

### 3. 发送消息给克劳德（直接执行）
```bash
python E:/zhuomian/vs_bridge.py --send "克劳德检查一下XXXX有没有XXXX"
```
执行流程：截图找文本输入框 → 点击 → 全选 → 粘贴文字 → 点击发送按钮
注意：VS Code 窗口需要可见（不能最小化）

### 4. 发送消息给克劳德（异步方式）
当主监控循环正在运行时，用文件方式避免冲突：
```bash
echo "克劳德检查一下XXXX有没有XXXX" > E:/zhuomian/vs_bridge_command.txt
```
主循环会在下一次轮询时（3~5秒内）自动读取并执行。

### 5. OCR 测试
```bash
python E:/zhuomian/vs_bridge.py --ocr-test
```
截图全屏 → OCR → 展示识别结果（不发微信）

### 6. 仅复制文字到剪贴板
```bash
python E:/zhuomian/vs_bridge.py --paste "文字内容"
```

================================================================
## 小龙虾自动化工作流示例

### 场景A：用户问"克劳德在干嘛"
1. 小龙虾执行: python vs_bridge.py --status
2. 读取输出，回复用户

### 场景B：用户发来指令给克劳德
1. 小龙虾判断消息是给克劳德的
2. 执行: python vs_bridge.py --send "用户的消息"
3. 回复用户："已转发给克劳德"

### 场景C：克劳德完成工作
1. vs_bridge 自动检测到"工作完·待输入文本"
2. 自动截图OCR提取 Thought for 内容
3. 自动通过 OpenClaw 发送到微信
4. 小龙虾收到后可以展示给用户

================================================================
## 状态机

  空闲 ──(检测到工作中图标)──▶ 正工作
  正工作 ──(检测到工作完毕图标)──▶ 任务完成 → 自动OCR发微信 → 空闲中
  任意状态 ──(两个图标都没检测到)──▶ 暂无工作在进行

## 依赖

Python 包:
- pyautogui (截图+鼠标键盘控制)
- opencv-python (模板匹配)
- easyocr (中文OCR)
- pyperclip (剪贴板)
- Pillow (图片处理)

OpenClaw (小龙虾消息发送):
- F:\Node.js\node.exe
- F:\node_global\node_modules\openclaw\dist\index.js
